# AH Snapshot

WoW Forever 拍賣場價量紀錄。用 Auctionator 全掃拍賣場時，自動記下每樣東西的價格和架上數量，推估賣了多少，
在遊戲裡用表格看哪些東西好賣。和朋友一起掃，大家的資料會自動合在一起。

## 安裝

1. 安裝 **Auctionator**（CurseForge）。
2. 把 `AHSnapshot` 資料夾放進
   `World of Warcraft\_forever_\Interface\AddOns\`。
3. 進遊戲，小地圖旁會多一個圓燈：**紅燈＝可以掃了，綠燈＝還在冷卻**。

## 使用

- 在拍賣場按 Auctionator 的「Scan」全掃。隔 30 分～2 小時再掃一次，就會開始有賣出量。
- 點小地圖的燈（或打 `/ahsnap show`）打開價量分析表。點欄位標題排序，點一列看那樣東西的歷史。
- 聯盟、部落、中立（藏寶海灣／加基森／永望鎮）是三個不同的拍賣場，資料分開記。
  分析表左上的「拍賣場」按鈕可以切換（左鍵下一個、右鍵上一個），也可以打 `/ahsnap ah 聯盟`、`部落`、`中立`。
- 最近 3 天保留每次掃描；更早的自動濃縮成每天一行（保留 30 天），存檔不會一直變大。
  要調整就打 `/ahsnap detail 天數`（每次掃描保留幾天）、`/ahsnap keep 天數`（每日紀錄保留幾天）。

## 和朋友一起蒐集

需要：大家都裝 **Google 雲端硬碟電腦版**，並把同一個共用資料夾加到自己的雲端硬碟。

1. 把 `AHSync` 資料夾放在電腦上任何地方（例如「文件」）。
2. 雙擊 `AHSync.vbs`。第一次會跳出設定視窗：
   - **你的名字**：朋友會看到這個名字。
   - **雲端共用資料夾**：按「瀏覽…」選那個共用資料夾。
   - **WoW 存檔**、**Battle.net** 會自動找好，通常不用改。
3. 之後看螢幕右下角的小圓點就好：

   | 顏色 | 意思 |
   |---|---|
   | 綠 | 待命，已同步 |
   | 藍 | 同步中 |
   | 黃 | 遊戲進行中 |
   | 紅 | 出錯了（滑鼠停在上面看原因） |
   | 灰 | 還沒設定 |

4. 照平常開遊戲就好。關掉遊戲時，它會自動把你的資料傳上去、把朋友的資料帶進來，下次進遊戲就看得到。
   也可以在圓點上按右鍵選「開遊戲」。
5. 右鍵選單勾「開機時自動啟動」，以後就不用再雙擊。

分析表上的「包含朋友資料」可以切換只看自己的（只影響最近 3 天；更早的每日紀錄是大家合併後的）。
朋友的資料要在 3 天內同步進來才算得進去，平常關遊戲就會自動同步，不用特別注意。

## 常見問題

- **雙擊 AHSync.vbs 跳出安全性警告**：從網路下載的檔案 Windows 會先問一次，按「執行」即可。
  不想每次被問，就在 `AHSync.vbs` 上按右鍵 →「內容」→ 勾「解除封鎖」。
- **圓點是紅的**：滑鼠停在上面看原因；最常見是雲端資料夾搬走了，右鍵「設定…」重新選。
- **沒收到朋友的資料**：等雲端硬碟同步完成，再關一次遊戲或按右鍵「立即同步」。
- **分析表一直看不到朋友的資料**：1.3.0 以前的版本會把同一個拍賣場記成不同名稱，請大家都更新到 1.3.1 以上。
  更新後第一次登入會自動整理舊資料。
- 需要回報問題時，右鍵「開啟日誌」把內容傳給我。
